# wdmatch — Level 2

Crie um programa em `wdmatch.c` que recebe duas strings. Imprima a primeira string somente se todos os seus caracteres puderem ser encontrados, na mesma ordem, na segunda string. Os caracteres da segunda string podem ter outros caracteres entre eles. Imprima uma quebra de linha no final; se não houver correspondência completa ou faltarem argumentos, imprima uma linha vazia.

Exemplo: `./a.out faya 'f this is a test y a'` imprime `faya`.

Compile com `gcc -Wall -Wextra -Werror`.
