# ft_strdup

Write a function with this prototype:

```c
char *ft_strdup(char *src);
```

Allocate enough memory for a copy of `src`, copy the terminating null byte as well, and return the new string. Return `NULL` if allocation fails. The caller owns the returned memory and will release it with `free`.

Submit your implementation as `rendu/ft_strdup/ft_strdup.c`.
