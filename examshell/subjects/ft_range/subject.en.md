# ft_range

Write a function with this prototype:

```c
int *ft_range(int start, int end);
```

Allocate and return an array containing every integer from `start` (inclusive) to `end` (exclusive), in increasing order. If `start` is greater than or equal to `end`, return `NULL`. The caller owns the returned memory and will release it with `free`.

Submit your implementation as `rendu/ft_range/ft_range.c`.
